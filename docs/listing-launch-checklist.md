## 4. Seed reviews (G2 / Capterra) — for REAL pilot users only

Reviews must be genuine — these are **prompts to hand a real pilot customer**, not copy to
post yourself. Give a pilot user the structure below and let them write it in their own words.

**Prompt for a GM / owner**
- What problem did Roomward replace? (group texts / paper logs / spreadsheets)
- Pros: one view of the property; front desk + housekeeping + maintenance on one system;
  per-property pricing instead of per-seat.
- Cons / room to grow: (ask them honestly — e.g. "still adding PMS integrations")
- Would you recommend it, and to whom?

**Prompt for a maintenance lead**
- How do you log and assign work orders now vs before?
- Pros: photos on every order; nothing lost between shifts; preventive schedules on assets.
- Cons: (honest)
- Star rating + one-line summary.

**Prompt for a housekeeping manager**
- How does the live board change the dirty→ready handoff with the front desk?
- Pros / cons.

**Prompt for a front-desk supervisor**
- Does seeing room-ready status in real time speed up check-ins?
- Pros / cons.

Aim for 3–5 real reviews in the first month — G2/Capterra ranking is review-weighted.
